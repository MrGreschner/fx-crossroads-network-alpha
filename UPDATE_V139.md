# v139 — Custom builds and classroom evidence

## Multiplayer
Every mode has a CUSTOM HEROES switch, OFF by default. Host controls it; guests receive its state. When OFF, choose an official hero. Public rooms only accept valid Forced Balance builds; private/code rooms and private hosts can use experimental builds. Turn off Public Room before hosting an experimental hero. You cannot turn customs off while a party member still uses one.

Custom artwork, animations and bounded ability instructions transfer over paced reliable chunks. Start waits for build acknowledgements. The host revalidates project data and power budgets. This is host-authoritative gameplay, not an authenticated anti-cheat system. Random-hero Arena continues choosing official heroes. Shared builds stay temporary on other players' devices, rather than entering their saved library.

## Forced Balance
OFF by default in all four Labs. Toggle ON to apply body and ability budgets. Higher damage, healing, range, area, charge, summons and control spend power budget: cooldown rises first, then excessive output is reduced. Extra health/protection trades against speed; the Hero Workshop offers speed or defence-first payment. Both mastery alternatives are checked too. Behaviour Lab bounds the decision language; health and attack tradeoffs happen in its receiving Hero/Enemy Lab.

Cyan rotating sigil + overhead diamond = custom build. Experimental builds also show violet sparks. Playtest uses blue inspection arcs; Media uses a green camera marker. Budget checking is an estimate, not a guarantee of competitive fairness. Record tests against several opponents.

## Classroom
Character Hall → Compare heroes: two official/custom builds side by side. Elder chat: type **teacher**, then **fx97**, for a local read-only review of creations, test evidence, mine progress and active Studio minutes. Quick test opens a saved hero in Training Yard. Time recording starts in v139 and only counts active input in Studio; it is neither attendance nor automatic grading. Existing Game Dev password remains R4ms!; teacher review does not unlock developer powers. Assignment submission and secure teacher accounts are future features.

## Mining and polish
New Mineral gallery: coal, silver, ruby, sapphire, diamond and moonstone unlock deeper down. Pixel specimens also appear in shaft scenery. Deposits collect during real elapsed idle time, respect flow/storage limits, and join Collect Depot. Assay a batch (up to 25 specimens) in a 60-second order for separate Mine Gold. Combat gold and bonuses are unchanged; Market continues using ore/gems for goods. Minerals and Studio activity travel with the existing player profile.

Lightweight entry ripples introduce Town, portal travel and Ram Descent. Identity cosmetics use a few vector strokes, not particle systems. Custom budget results are cached for drawing instead of decoding artwork every frame.

This ZIP is the full editable project. It is not an exported browser or Windows build.

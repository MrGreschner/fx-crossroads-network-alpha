Account controls

Search game usernames or private six-digit game IDs such as 004821. IDs are randomly generated; we do not request names, initials or official student numbers. Keep your student-to-ID list in a school-approved system. Private game IDs never appear in community records. Assigning a role does not change the ID. These roles grant Academy access, never administrator access.

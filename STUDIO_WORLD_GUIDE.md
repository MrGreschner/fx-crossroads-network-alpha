# Student quick start — objects, realms and evidence

1. Enter Crossroads Studio. Choose **Object & Raster Lab**.
2. Pick a starter or Clear / Start fresh. Draw your own version with layers; use hex colours, selections and masks. Name it and record credits.
3. **Finalize object**. It is immediately available to Realm Builder. Download the project for editable source, or Download flattened PNG for the game image.
4. Open **Realm Builder**. Enter width × length. Record your vision before placing work if completing DES2035.
5. Paint terrain. Edit selected terrain to decide whether it blocks movement or projectiles. Add your props and enemies; place spawn and exit.
6. **Check routes & collision**, then **Finalize & Play**. Use your Workshop hero to explore and battle. End test returns to the builder.
7. Student Mode: choose your active module in the learning portfolio. Attach your finalized props and tested realm (or use Submit finalized work for the current artifact). Submit a short initial vision, credits and feedback where requested; the actual artwork is evidence for practical production/tool-use outcomes.
8. Keep both an individual project download and your player profile ZIP. `objects/` and `realms/` make the files easy to find for sharing with a teacher or classmate.

To add a hero form: Hero Workshop → Artwork → Alternate Forms → Add form → Draw / upload. Under Abilities, select the appearance beside Transform into and set its duration. The form is also in the shared hero JSON and profile ZIP.

When reviewing, teachers see saved source and snapshots, not a changing live draft. A full progress bar means evidence is present for review, not that a credit has automatically been earned.

# V228 art provenance

Six original enemy-family atlases were generated/edited with the built-in image generation tool. Each uses its realm's existing enemy artwork as identity reference and Young Ram as the coarse matte style reference. A separate Mask Duelist attack correction removes the extra hand and preserves one sword and one staff. Prompts: tools/enemy228_prompts.json.

Selected transparent source sheets, 64x64 runtime frames and crop/scale metadata are in assets/enemy228. The original family sheet is retained alongside the selected corrected Mask Duelist attack source. Existing root PNG aliases and matching imported textures resolve the same frames in solo/co-op and other uses. Shared enemies retain the new artwork wherever their existing ID is used.

No external asset pack or runtime image-generation service is used. Source sheets remain in the editable project; only small runtime frames are added to the game pack. The three shared Crossbell school supplies retain their accepted V227 artwork. All hero artwork is unchanged from V227.

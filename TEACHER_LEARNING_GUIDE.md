## Student workflow

1. Visit the classroom Education Guide desk or use the top Education Guide button. Select a module.
2. In Brief & outcomes, read the project and evidence requirements. Enter a class alias.
3. Record the brief, research, rough alternatives and chosen approach in Journal before building. Entries append rather than silently replace earlier work.
4. Build in Studio, Media or Market. Use Save assignment snapshot or Attach work to link frozen project versions. Add copyright/permission sources and your explanation.
5. Use Practice checks where available. For programming, open the IPO workbench, edit source, enter JSON input and predicted output, run cases, revise and save a program snapshot.
6. Record tests, feedback, decisions, workstation routines, competencies and pathway reflection where the chosen module requires them. Safety/teamwork evidence needs teacher observation as well as written claims.
7. Submit & feedback freezes the journal and linked snapshots. This keeps the version the teacher assessed separate from later edits.
8. Join the teacher's ED room to send your current education portfolio automatically. Use Send latest progress after further work. Accept returned feedback for matching frozen submissions.
9. Download your player profile. It includes Studio creations, learning evidence, access flags and ordinary progress.

## What is automatically marked?

- Concept exercises for COM1145, COM1035 and CSE1110: answers are scored against the saved question set.
- IPO predictions: the saved source is interpreted again using each saved test's inputs. Output/error is compared with the student's prediction.
- Graphics: presence of valid paired PNG and safe SVG exports.
- Motion: presence of at least two distinct frames.

These scores/checks are evidence, not automatic credit. A trivial test, copied answer or pair of different images does not demonstrate an entire outcome. Teachers assess explanation, intent, design quality, revision, copyright, safety, teamwork and presentation.

The IPO workbench is a small interpreted teaching language, not unrestricted GDScript or a native compiler. It supports sequential `input name`, `let name = expression`, and `output expression`; numbers, short text and + − × ÷. It rejects external calls and file/system access. Use a full IDE/compiler lesson too when needed to meet the source-to-executable portion of CSE1110.

## Teacher class view and marking

Host Submission room from Class view. The private ED code has 31 student seats and a separate teacher host. Joining explicitly discloses that it sends the student's educational journal, attached work, submitted snapshots and feedback—not their full game profile or desktop. Teachers receive and retain records locally. The server only relays bounded transfers.

Class cards show alias, last received time, evidence bar, submissions, number of outcome ratings and automatic checks. Review work & mark outcomes opens that student's frozen evidence. Inspect artwork/source/tests, choose each outcome rating, add feedback and an optional 0–100 score, and save. Live students can accept the returned feedback. A fresh upload preserves ratings when submission ID and content digest match; changed submissions require a new review.

Use Download class records and Restore class backup to move a teacher-only record set. Download class summary gives a readable report. Download the player profile to preserve the complete teacher account, access flags and class records. Remove saved class asks for confirmation; keep a backup first.

The dashboard supports up to eight saved room groups, 93 received student records and 32 MB of class data. Individual live portfolios are limited to 4 MB; larger work can be reviewed locally or through a downloaded portfolio file. The service allows four concurrent uploads per room and queues other students to retry. Rooms expire after two hours. Reopening a room creates a new class code/group; stable learner IDs distinguish same-named students within a group.

Teacher Mode also allows a 31-seat view-only lesson broadcast. This uses the existing lightweight 2 FPS in-game screen stream, not OBS-quality video or desktop capture. The broadcast automatically holds its last frame while private teacher/class assessment panels are open, then resumes when they close. Spotlight places an animated pointer on the next clicked screen position for eight seconds; it grants no combat powers.

For local review, open Local portfolio. For a one-student remote review, the earlier RV code flow remains available and requires student approval. Downloaded feedback can also be imported into the student portfolio when the teacher is offline.

## Assessment cautions

Evidence/readiness bars measure requested evidence presence. They are not grade percentages. Timestamps record local order, not secure provenance. Teachers decide whether work meets outcomes and may require additional off-game tools, discussion, observation, presentation or assessment before awarding credit.

# V226 art provenance

Lyra Galeweaver was generated using the built-in image generation tool. The user's supplied storm-sorcerer image guided her design; existing Young Ram and Rune Duelist sprites guided visual simplicity and shading. A targeted correction placed the staff consistently on the established side in every cell. Prompt and correction description: tools/hero226_prompt.json.

Selected original transparent sheet: assets/hero226/twisterspell_source.png. Normalized frames and crop/scale metadata: assets/hero226. Cached front-facing alternate walking frames use the Lyra foot rectangles in scripts/hero_walk222.gd. Original generated move poses remain in the source sheet; normalized runtime moves use fixed idle heads and torsos to avoid bobbing or one-foot-only stepping.

All other art from V225 is retained. No third-party asset pack or new per-frame image processing was introduced. The existing small-texture cache is used.

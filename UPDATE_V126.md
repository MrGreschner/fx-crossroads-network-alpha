# v126 — Crossroads Studio polish and classroom assignments

Creator interfaces now share a teal, parchment and gold visual style with consistent type, spacing, focus and hover states. Primary actions use green accents. Lightweight opening fades give transitions a softer feel.

- Studio landing page with two clearly described tool cards.

- Test reports: separate measurement, method and reflection pages.
- Mr. G: clearer classroom header, scrollable welcome cards and corrected chalkboard spacing.

## Assignment board

A physical pinned board sits on the classroom wall. Use E nearby or click Assignment board in the classroom header. There are six briefs: playtesting; hero and enemy creation; behaviour redesign; realm design; tutorial and promotional video creation; music and sound creation.

Each brief provides a purpose, method, task, submission list and review criteria. Playtesting asks for three evidence-backed improvements and a report describing coverage and methods. Enemy AI and realm construction are clearly identified as Godot project work, not features the current Studio can generate.

Teachers can edit content/studio/assignments.json. Entries use title, summary, body, task, deliver and criteria fields. These are informational briefs, not automatic grading or submission uploads.

## Deployment

Re-export the Web and Windows builds in Godot and replace your itch.io uploads. This ZIP is the editable project, not the playable Web export. No Render or room-service changes are needed.

Official heroes, attack behaviour, game balance and profile format are unchanged.

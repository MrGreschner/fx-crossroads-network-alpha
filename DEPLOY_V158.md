# Deploy v158

Open this fresh editable project in Godot 4.5.1 and let assets import. Export Web for itch.io using your existing preset; upload the exported Web ZIP, not this editable source ZIP. Export Windows separately for the download button. Verify Options diagnostics reports v158 on both exports.

On Render, set FX_GAME_VERSION to 158 and redeploy to update the downloaded-client version check. If using the bundled default instead, update room_service/release.mjs. No new room protocol or dependencies are required for these local features.

Quick checks: walk beside Healer House and Wayfinder Lodge; use Basic setup at the Market, wait for a profitable day, collect the supply dividend, then buy supplies. Back up profiles before replacing installed builds.

# V227 art provenance

Five original enemy atlases were generated/edited with the built-in image generation tool. Each used that realm's existing enemy designs as identity references and Young Ram as the coarse matte style reference. A separate four-pose Glacier Hound correction replaces the side profile with neutral front-facing quadrupedal anatomy. Prompts and correction: tools/enemy227_prompts.json.

Original selected RGBA sheets, cropped 64x64 runtime frames and normalization metadata are in assets/enemy227. The original five family atlases are retained; Glacier Hound uses its separate corrected *_source.png. Existing root PNG aliases and imported compatibility textures resolve the same new frames in solo, co-op, journals and studio examples. Shared school creatures retain this updated identity in other school realms too.

No external asset pack or runtime image-generation service is used. Original/source sheets are retained in the editable project; only small runtime frames are added to the game pack. Bramble and Thorn Archer retain their already accepted V220 artwork. Hero artwork is unchanged from V226.

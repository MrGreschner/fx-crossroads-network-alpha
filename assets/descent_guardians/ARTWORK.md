# V202 guardian sprites

Created with the built-in image generation tool in transparent-background mode. Each PNG is a single original sprite; alpha is preserved. The game caches trimmed, downscaled textures and animates them with draw transforms. These are project assets, not external image links.

- assets/descent_guardians/cavern_warden.png — floor 5 and sentinel encounters
- assets/descent_guardians/basalt_ram.png — Basalt Gatehorn, floor 10
- assets/descent_guardians/garnet_widow.png — Garnet Widow, floor 20

## Final prompts

### Cavern Warden
Use case: stylized-concept. Production sprite for Crossroads: Realms Beyond, top-down 2D dungeon game. One isolated full-body Cavern Warden, the first underground sentinel boss. A broad upright cave guardian made of weathered blue-grey stone, carrying a rough heavy stone maul with a crystal inset, broad asymmetric shoulders, short powerful legs, distinct rectangular carved face with two teal glowing eyes, small mineral growths on shoulders. NOT a ram, no horns, no armor helmet, no clothing. Clean polished hand-painted fantasy game sprite with chunky readable silhouette and restrained cel shading, 3/4 overhead view facing down-right, entire character and maul visible centered with ample transparent padding. Intended to read at 140 pixels high. An ancient patient stone guardian, impressive but approachable adventure style, not horror. Genuine transparent background, no floor, no cast shadow, no circle, no halo, no UI, text or contact sheet. Single finished game sprite.

### Basalt Gatehorn
Use case: stylized-concept. Asset type: production sprite for Crossroads: Realms Beyond, a top-down 2D fantasy dungeon action game. Create ONE isolated full-body enemy boss sprite, Basalt Gatehorn: a formidable quadrupedal mountain ram assembled from jagged dark basalt plates, huge unmistakable curled ivory-stone horns, weathered chisel marks, a few subtle amber mineral cracks, heavy split hooves, broad low charging silhouette. Three-quarter overhead view facing down and slightly right, consistent with a top-down 2D game, entire character visible with generous transparent padding, centered, no cropping. Beautiful clean hand-painted game art with restrained cel shading, strong readable outer contours, chunky shapes and selective detail that reads at 140 pixels high. Mature adventurous charm, not horror and not photorealistic. Genuinely transparent background, no scene, floor, background shadow, halo, UI, text, border, multiple characters or contact sheet. This is an actual first dungeon boss, visually impressive and unmistakably a RAM, not a humanoid wearing armor. Render a finished polished sprite suitable for compositing into a Godot game.

### Garnet Widow
Use case: stylized-concept. Asset type: finished production enemy sprite for a top-down 2D fantasy dungeon action game Crossroads: Realms Beyond. Create ONE isolated full-body Garnet Widow boss: an imposing eight-legged cave spider, NOT humanoid and NOT a ram. A faceted deep ruby-garnet crystal abdomen, charcoal chitin plates, eight elegant articulated slate-black legs with garnet highlights, two powerful ivory mandibles and a small readable cluster of warm rose eyes. Beautiful polished hand-painted game art, restrained cel shading, strong silhouette and clean contours. Readable and impressive when downscaled to about 150 pixels wide, details concentrated on the garnet abdomen and face. Top-down three-quarter overhead angle facing down and slightly left. All eight legs and all extremities fully visible, centered with ample transparent padding. Mature fantasy-adventure atmosphere, no gore or horror realism. Genuine transparent alpha background, NO floor or environmental shadow, no halo, no circular frame, no UI, no text, no scene, no contact sheet, no additional characters. A distinctly different silhouette from a quadrupedal stone ram: broad low arachnid body with a crystalline abdomen rising behind its head. Finished Godot-ready single sprite.

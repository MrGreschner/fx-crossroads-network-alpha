# v150 — Create and play first; education is optional

## Studio and business UI
- Object & Raster Lab is now **Object Lab**, including the Studio hub, lab header, guide and Elder explanation. Drawing tools are labelled pixel tools. Internal file names and the official Raster Graphics curriculum module names are retained.
- Normal Hero Workshop shows hero details, optional lore, art, abilities, passives and mastery. The separate design concept prompt appears only in active Student Mode.
- Test tools and performance measurements stay available to everyone. Prediction, method, observations and next-change fields, plus their report display, are Student Mode extras. Normal readable reports omit the worksheet sections.
- Realm Builder opens with map size, atmosphere and terrain controls. Initial vision and the module-recording button appear only in active Student Mode.
- Market forecasts, reflection fields, written history and assessment guidance appear only in active Student Mode. Normal trading retains prices, customers, promotion, branding, stock, timed days, finance reports and optional trading tips.
- Ability, Enemy and Behaviour Lab submission/journal controls remain gated by active Student Mode. Optional design, code and pixel-art help remains public; writing tasks are hidden when Student Mode is off.
- Switching Student Mode off does not erase stored plans, notes, projects or assignments. Reopen a screen after toggling to rebuild its controls.
- No planning text is required to build/finalize/play normal custom creations. Artwork warnings describe animation completeness instead of assignment submission.

## Crossroads Market exterior
Expanded into a trading yard with a larger warehouse/loading hall, mineral stockpiles, gem counter, stacked shipping crates, ram workers carrying boxes and an animated cart. Collision protects stock and buildings while leaving the entrance reachable. The approach road follows the new doorway; the lot is reserved from scattered town trees. Animation uses a few culled drawing operations rather than extra simulated combat entities.

Official hero attacks, run balance, currencies and existing account schemas are unchanged from v149. This is editable Godot source, not a playable export. No deployment was performed here.

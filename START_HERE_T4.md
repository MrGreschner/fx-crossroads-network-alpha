# FX Crossroads Network Alpha T4

Read NETWORK_T4_README.md for deployment. Use this source folder for the fx-crossroads-network-alpha repository and Render. Upload the separate FX_Crossroads_Network_Alpha_T4_Web.zip to FX Connections Lab on itch.io.

Update BOTH server and browser build. Health must show ready: true, build: T4, protocol: 3. Start with 1 CPU / 2 GB for the school test; do not treat Render Free as the multiplayer capacity baseline.

NETWORK_T4_VALIDATION.md gives passed checks and the explicit limits of the 30-minute evidence. Older NETWORK_T3 / T2 and v-number guides are retained historical references, not instructions for deploying T4.

The main game's living-town/day-and-night update remains separate.

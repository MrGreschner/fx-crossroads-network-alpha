# V250 artwork and reproduction

Nine selected original images were produced with the built-in image-generation tool: amber/red skiffs, blue/olive launches, dock timber, shoreline gravel, bait stall, cargo and harbor lamp. Exact prompts are in assets/marina250/prompts.json; source PNGs and SHA-256 provenance are retained under assets/marina250/sources and provenance.json. References in tools/marina250_references preserve the original marina identity and the accepted Ram/Cat/Book/Dawnblade style board. Existing V244 basket, net and rope sprites are reused directly. No third-party asset pack was added.

From the Editable project, run `python3 tools/prepare_marina250.py REVIEW_OUTPUT` (Pillow and NumPy required), then `python3 tools/bake_shore250.py` and `python3 tools/clean_bank_cache250.py`. These scripts use the retained selected originals by default. The preparation step cleans alpha, crops and fits assets with nearest-neighbour scaling, and records painted bounds. Both skiffs retain a 67x121 painted hull, both launches a 90x184 hull. The procedural work only arranges the generated material ribbon around the unchanged water boundary and bakes existing scene geometry; it does not synthesize character artwork.

Import in Godot 4.5.1, then run `qa/v250_bake.gd` through a transparent OpenGL viewport to regenerate deck.png, fittings.png and static.json. The script hides autoload overlays and fixes content scaling before capture. `tools/verify_marina250.py REVIEW_OUTPUT` checks exact original cache pixels, bridge exclusions and shoreline coverage. Runtime assets are in assets/marina250; original sources, references, prompts and provenance are excluded from Web/Server runtime export. Reproduction hashes are retained in qa/evidence250/art_reproduction.json.

Release tooling is in tools/release250. Build and release scripts expect a workspace with baseline249 ZIPs and extracted server249/web249 alongside project250, as used during verification. V250_Previews.zip supplies all full-resolution native/Web captures; qa/evidence250 retains machine-readable results and the contact sheet without duplicating the large review set in Editable.

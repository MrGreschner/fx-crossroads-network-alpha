# v132 — Partner Studio and cosmetic rewards

## Playtest Mode
Field Research is now called Playtest Mode. Type `playtest` to Elder Ram. A thin blue border marks the session; F8 toggles observation tools. Normal combat remains unchanged. Checkpoints, FPS evidence and the notebook are available. No player progress is saved, and profile transfers remain blocked. Exit restores your saved profile. Game Dev remains a separate mode with unlocks and powers.

## Partner Up — two-person Studio
Open Crossroads Studio and choose **Partner up**. Enter a display name and **Create session**; give the SP invite code to one partner. They open Studio → Partner up → enter the code → **Join partner**. Both need v132 and the updated Render room service.

One student holds the shared pencil. The writer chooses any of the four labs and edits the shared draft. The partner sees the same artwork, values and code. **Request pencil** asks the current writer; **Pass pencil** hands over after the latest valid draft has finished transferring. The writer's lab changes sync approximately once a second. Invalid or incomplete code stays local until valid. This is turn-taking collaboration, rather than simultaneous edits or desktop screen sharing.

**Download shared** works for either student. It exports the current hero, ability, enemy or behaviour in its ordinary portable JSON format. Each student can also save or add the project locally after leaving. Both copies are independent after export. Joining replaces your open draft, but does not replace your saved library. A local backup of the previous open draft is stored as `user://fx_partner_previous.json` (the envelope contains its lab kind and value); download important work before joining.

Only two seats are allowed. The last shared draft stays on both devices after a disconnect, and the remaining student receives the pencil. A session disappears when both leave. Share the code privately; no account or public Studio listing is required. Drafts are relayed through the room service and held in memory only during the session. No arbitrary executable scripts are accepted; the existing bounded project and code validators still apply.

## Weekly cosmetics
Open **Profile / Mastery / Town → Profile → Cosmetics**. Weekly damage in normal play unlocks:

- 10,000: **Wisp Skull** — a subtle floating skull.
- 20,000: **Silver Revenant** — a skull with an orbit and small horns.
- 30,000: **Astral Sovereign** — a crowned skull with moving lights.

Choose one effect, the daily reward, or none. Effects are cosmetic and visible to other players. Weekly damage and rewards reset each Sunday at **00:00 local device time**. The downloaded profile carries the current week's progress and choice, but expired weekly effects are removed when loaded. Training, Studio/Rift practice, Game Dev and Playtest do not earn rewards. The offline device clock drives the calendar; these are not server-verified competitive rewards.

## Permanent Easter Egg
Earn all four expert-realm badges — Astral Rift, The Chimevault, Ebonwake Citadel and The Shattered Oath — to unlock **Easter Egg**. The small hovering, shimmering egg can be equipped in Cosmetics. Its unlock follows your permanent realm badges and does not expire with weekly rewards. Game Dev can preview cosmetics without saving unlocks.

No official hero attacks, statistics or artwork were changed in this update.

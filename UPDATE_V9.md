# Version 9

- Warden removed from the playable roster and character registry. An old profile that selected Warden safely falls back to Ram.
- Baseball hero renamed The Diamond Scout.
- Golf hero renamed The Fairway Ranger.
- Character Hall uses one scrollable roster, with a visible scrollbar. Use mouse wheel or Up/Down to scroll; click a row to select and see its details. Number keys 1-9 still select heroes directly. Selection automatically scrolls the chosen hero into view.
- All version 8 maps, balance settings, abilities and other changes are included.

# Crossroads V305 Wayfarer Wilds

Wayfarer Wilds has seven ground materials and 26 scenery designs. Willowrest, the Abandoned Camp, Mosswheel Mill, river crossings, the Fallen Wayshrine, Glowroot Grotto, Heart Chamber, Rimecrest and Skyworks have their own visual treatment. Textures use three compact sprite sheets and visible terrain surfaces use repeating materials.

Ten enemies are exclusive to Wayfarer Wilds. Thornveil Bandit, Ambercap Slinger, Hollowroot Keeper and Heartwood Warden live in the forest and dungeons. Rimehare, Hoarfletch Archer and Bellstone Sentinel guard Rimecrest. Brassback Beetle, Valvewright and Reedjaw guard Skyworks. Each has a new front-facing sprite and a distinct ID. Existing health, attack behavior, spawn coordinates, quest groups and progress keys carry forward. Existing Wayfarer journal discoveries still reveal the corresponding new portraits.

The packed Godot fixture passed 317 checks. It completed all five solo quest chains, tested Bellstone's warning and slam, verified all 32 authored encounter placements in solo and co-op, and inspected the two-player authority snapshot. Eight native game views were rendered and reviewed. Browser and live classroom playtesting are pending.

## Install

Deploy the matching V305 Server Update to Render, retaining the existing service environment and database. Upload the intact V305 Web ZIP to the itch.io HTML game page and mark it playable in the browser. The PCK is assembled from small verified parts inside the ZIP.

## Restore editable source

Overlay all four V278 Editable ZIPs, then final V293 RecoveryDelta, final V304 RecoveryPatch, then V305 RecoveryPatch. V305 is a compact overlay over exact V304. Original art and generation prompts are under art_masters in the patch. Keep V304 for rollback.

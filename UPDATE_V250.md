# Crossroads: Realms Beyond — V250

Completed from the authoritative V249 Editable, Web and Server Update packages. Build: V250-marina-portraits-prompts. Nothing deployed.

The marina now has detailed cedar and red skiffs, slate-blue and olive launches, timber docks, bait stall, cargo and harbor lamps in the accepted V207/V208 soft-edged, matte pixel style. The rowing boat used during voyages shares the new amber skiff design. The existing oars, wake, gentle bobbing, mooring rotations, light points and nighttime glow remain. Existing V244 basket, net and rope artwork replaces the old geometric fittings. Each boat retains its own color, location and visible world footprint.

The uniform grey-green water border is replaced by an irregular gravel bank with a damp water-facing edge around the marina and along both riverbanks. Its width and contour vary; the two existing bridge crossings remain clear. These are visual overlays only: the exact V249 water, deck, collision, movement, entrance, berth, service, cargo and NPC route definitions are preserved. Only the old bank-colored pixels are made transparent in two replacement static cache pages.

Community Records and other shared portrait views now show neutral hero poses on a common stage, using the same painted-body size factors as gameplay. Small heroes remain small relative to tall heroes. Crowns follow each current frame's painted top, including ears and rotated forms, with a minimum head clearance. Traveler titles and floating cosmetic groups occupy separate relative positions; ground rings retain their grounded placement. Solo, arcade, offline lobby, network lobby and the Gleam Atelier preview use the same geometry helper. Dense network-lobby award collections have a bounded icon row above the hero; no owned awards or eligibility rules change.

Interactions now use a high-contrast framed card with a clear E keycap (or tappable TAP keycap on mobile). Informational hints show TIP. NPC messages use a separate framed panel with a speaker label, wrapped text and a scroll area for long messages. The cards remain above scenery and night lighting, adapt to small landscape screens, and hide behind menus/clean captures. Existing interaction controls, hint text, message duration and dialogue remain unchanged.

Install Server Update before Web so client/server build stamps match. Preserve the deployment's existing configuration, accounts and persistent data and retain a backup. Full-resolution review captures are in V250_Previews.zip; the Editable contains compact evidence and machine-readable results.

No deployment, real account/login, live backend or physical school-computer frame-rate benchmark was performed. Offline local network-lobby rendering was checked; real remote multiplayer connectivity was not tested. All V249 gameplay and artwork fixes remain in place.

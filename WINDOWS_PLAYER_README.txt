FX CROSSROADS v122 - WINDOWS EDITION

Extract the WHOLE ZIP, then open FX_Crossroads.exe inside the extracted folder.
Keep FX_Crossroads.pck and all DLL folders beside the EXE. Do not run from the ZIP.
You do not need Godot to play. This download is for Windows PCs, not phones.

Multiplayer uses the same Render room service as the browser game. Use matching
versions. Native WebRTC is included by the builder; test Windows-to-Windows and
Windows-to-browser matches on your school network before classroom rollout.

Keep your progress: download your profile in the browser while in town, then
upload that profile in the Windows game's main menu. Browser and Windows saves
are separate. Game Dev testing profiles cannot be transferred.

Options on the main menu include frame rate, School performance mode and
local diagnostics. The Windows edition bypasses Chrome/WebGL2, but still needs
working graphics drivers and cannot guarantee immunity from all crashes.

If a school policy blocks the executable, ask IT to approve this specific game.
The original WebRTC ZIP is included to preserve third-party license materials.
